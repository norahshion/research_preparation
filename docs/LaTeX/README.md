# LaTeX 入門と環境セットアップ

このディレクトリは、LaTeX の基礎、すぐに動くテンプレート、そして VS Code 環境での LaTeX 開発手順をまとめます。

目的:
- 初学者が最小限の準備で文書を作り始められるようにする
- テンプレートからすぐに PDF を出力できる状態を提供する
- VS Code 上での便利な開発ワークフローを提示する

構成（大枠）:

1. `basic.md` — LaTeX の基本記法（文書構造、セクション、数式、図表、参照、文献）
2. `template.tex` — 最小限で動くテンプレート（plate.tex として同梱）
3. `vscode-setup.md` — VS Code での LaTeX 環境構築手順（拡張、PDF レンダリング、ビルド設定）
4. `tips.md` — コンパイルエラーのよくある原因と対処、推奨パッケージ

推奨ワークフロー（初心者向け）:
- 1. システムに TeX 配布 (TeX Live / MiKTeX) をインストール
- 2. VS Code と `LaTeX Workshop` 拡張を導入
- 3. `template.tex` をコピーして内容を書き換え、ビルドして PDF を確認

次の作業として、`basic.md` と `tips.md` を必要な分だけ追記可能です。テンプレートと VS Code 設定は続けて作成します。
