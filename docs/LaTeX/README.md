# LaTeX 入門と環境セットアップ

このディレクトリは、LaTeX の基礎知識、すぐに動く実用テンプレート、および VS Code での高速・全自動な LaTeX 開発環境の構築手順をまとめています。

## 🎯 目的
- 初学者が最小限の手間で環境を整え、論文や報告書の執筆を開始できるようにする
- テンプレートを用いてすぐにビルド（PDF出力）できる状態を提供する
- VS Code 上での快適な執筆・プレビュー連携ワークフローを提示する

---

## 📂 構成と提供ドキュメント

現在、以下のファイルが配置されています。

1. **[VS Code での LaTeX 環境構築手順](./vscode-setup.md)**
   - TeX Live の最小構成インストール、VS Code 拡張機能の設定方法。
   - **ポイント**：環境変数に依存しない「実行ファイル絶対パス指定」を採用し、PC環境を選ばない極めて安定した自動ビルド（保存時ビルド、SyncTeX連携）を構築します。
2. **[LaTeX 最小構成テンプレート](./template/template.tex)** (`template/` ディレクトリ内)
   - 学術論文や報告書でそのまま使える、日本語対応（upLaTeX）のテンプレートファイルです。
   - 参考文献定義用の `.bib` ファイルや、論文レイアウト用のスタイルファイル（`.sty`）も同フォルダ内に同梱されています。

---

## 🛠️ 推奨ワークフロー（初心者向け手順）

1. **システムの基盤構築と VS Code 連携**
   - まず [vscode-setup.md](./vscode-setup.md) を開き、手順に従って **TeX Live** のインストールと **VS Code** の設定（`settings.json` の書き換え）を行います。
2. **テンプレートの確認**
   - [template/](./template/) ディレクトリをコピー、または中の `template.tex` をベースに新規 `.tex` ファイルを作成します。
3. **ビルドとプレビューの実行**
   - 作成した `.tex` ファイルを VS Code で開き、保存（`Ctrl + S`）すると自動ビルドが走り、`out/` フォルダ以下に PDF が出力されます。
   - 画面右上の「View LaTeX PDF（虫眼鏡マーク）」を押し、エディタの右側でプレビューを表示しながら執筆を行います。
